# 採血データなしでα1-mg除去率予測モデル
## 📁 ファイル構成

- `alpha1mg_ensemble_model.ipynb`: LightGBMとニューラルネットワークのアンサンブル学習モデル

- 5-Fold Cross Validation による検証

## 🚀 実行方法

このノートブックはGoogle Colabで実行することを推奨します。

1. Google Colabで開く
2. ランタイム → すべてのセルを実行
3. データファイルは `/content/drive/MyDrive/df_train_ta.xlsx` に配置
